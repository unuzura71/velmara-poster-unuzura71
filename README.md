**Velmara — Where the Sea Learns to Fly.** A vintage travel poster for a place that
does not exist: a white cliff city of domes and towers where the waterfalls rise
from the sea into a golden sky, and the sailboats drift among them.

The repository holds the poster as `entry.png` and a small Node program, `main.ts`,
that copies it, byte for byte, to the output folder — no network, no dependencies,
the same bytes on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

That writes `out/entry.png`, the poster the judge sees.
