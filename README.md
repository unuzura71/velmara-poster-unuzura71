**Velmara — Where the Sea Learns to Fly.** A vintage travel poster for a place
that isn't there: a white cliff city of domes and towers, waterfalls climbing from
the sea into a golden sky, sailboats drifting between them. You can't buy a ticket
there. You can only look at the poster and wish you could.

This repository holds the poster itself as `entry.png`, and a small Node program,
`main.ts`, that writes it to the output folder byte for byte — no network, no
dependencies, the same file on every run, so the judge sees exactly the poster
that was drawn.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

That writes `out/entry.png`, the poster the judge sees.
